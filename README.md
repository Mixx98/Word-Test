# 📝 Word Test

텍스트 파일에 적어 둔 단어로 **영단어 시험**을 보는 콘솔 프로그램입니다.

## 주요 기능

- **문제 유형 선택** – 뜻을 보고 영어 맞히기(1) / 영어를 보고 뜻 맞히기(2)
- **출제 순서 선택** – 파일 순서대로(1) / 랜덤(2)
- 시험이 끝나면 **정답률**(맞힌 개수 / 전체) 출력

## 단어장 형식 (`word.txt`)

한 줄에 `영어 = 뜻` 형식으로 적습니다.

```
such as = ~와 같은
apple = 사과
```

## 파일 구조

```
├── word test.py   # 메인 프로그램
└── word.txt       # 단어장
```

## 사용 기술

`Python`

## 실행 방법

```bash
python "word test.py"
```

> 코드 안의 단어장 경로가 `C:\VS CODE\Word Test\word.txt`로 고정되어 있습니다. 다른 위치에서 실행하려면 이 경로를 `word.txt`로 바꿔 주세요.
